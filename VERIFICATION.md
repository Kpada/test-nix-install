- nix --version returned 2.34.7.
- nix-store --verify --check-contents completed successfully.
- nix eval evaluated an expression correctly.
- An offline derivation using /bin/sh built and produced the expected contents.
- GITHUB_PATH and GITHUB_ENV contained the expected profile and Nix variables.
- An incorrect archive checksum was rejected before creating /nix.
- Installing over an existing nonempty /nix was rejected.

Environment limitation: this container only provides UID 0, lacks root's DAC
override capability, and cannot create or switch to a regular user. For the
extraction check, a test-only tar wrapper made GNU tar use its ordinary-user
directory-permission handling. The wrapper was not used for Nix and is not
included in this repository. Nix ran as root inside the test container.

This is a container smoke test, not an execution on a GitHub-hosted runner.
The included release workflow tests the actual ordinary-user x86_64 installation
and offline build on ubuntu-24.04 before publishing.
